# news-library

Особиста оперативна бібліотека: додати посилання, швидко оцінити матеріал,
зберегти доступний текст і дайджест та знайти потрібне пізніше.

**Стан:** підготовлено специфікацію, HLD і пілоти оцінювання. Застосунок
має SQLite-сховище, стійку чергу, історію оцінок та FTS; HTTP/UI
додаються наступним кроком M1. Початкова основа — репозиторій
https://github.com/valpere/news-library, коміт `955c6c3`.

## Перевірка підготовленого пакета

```sh
make check
```

Потрібні Python 3 і `tumanomir` (`.build/tumanomir`, PATH або змінна
`TUMANOMIR`). `make spec-check` перевіряє контракт і зв'язки з HLD;
`make check` додатково перевіряє документи та збережені пілоти.
Перевірки офлайн, без запитів до моделей. Команди
збірки й запуску Go-застосунку з'являться під час реалізації першого етапу.
Скрипти пілотів у `scripts/` можна продовжувати окремо; їхній `run`
викликає хмарні моделі. Оригінали Obsidian та LLM Wiki залишаються зовні.

Тести сховища (Go 1.26+): `make test` — race detector та `go vet`.
